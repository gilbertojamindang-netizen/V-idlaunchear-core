# Vøidlaunchear

**Vøidlaunchear** is an unofficial modified Android launcher for Minecraft: Java Edition, based on [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2).

This repository keeps the upstream launch engine and Android project structure while applying a separate app identity and VØID visual branding.

## Status

- Zalith Launcher 2 source is present as the project foundation.
- Vøidlaunchear app name, app ID, first-run notice, and adaptive icon branding are being customized.
- A successful APK build and real-device gameplay test have not yet been confirmed.
